Vehicle software & hardware compatibility

The SWT workflow checks installed ECU hardware against software release information in EPDM before an update. If hardware does not match, replacement and a remodelling list may be required before deployment.

EPDMECU CompatibilityDTSRelease Workflow
Typical flow: check current hardware and selected release compatibility → flash compatible hardware or order a replacement when there is a mismatch → verify the required software release and prepare the remodelling list with the right SA codes → deploy through DTS, which connects to the vehicle to flash the ECU.
